# Levy Home MVP Scope

Levy Home is an iOS-first notification layer for a small set of home events.
Home Assistant remains the automation brain.

## In Scope

- Garage opened
- Garage closed
- Garage open for 10 minutes
- Garage opened between 10 PM and 7 AM
- Garage still open at 10 PM
- Doorbell pressed later
- Basic eufy person/motion events later if reliable
- Recent event timeline
- Push notification pipeline
- Debug tooling

## Out of Scope

- Full Home Assistant dashboard
- Camera live view
- Two-way talk
- Hue/Lutron/LIFX controls
- LG ThinQ
- SmartThings
- Android
- Apple Watch
- Automation builder
- Production auth
